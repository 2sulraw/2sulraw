## Featured projects

### [Mazda Browser](https://github.com/2sulraw/mazda-browser)

A browser engine written in pure Rust from scratch — HTML/CSS parsing, layout, a
CPU software rasterizer, and its own JavaScript interpreter. No third-party engine
code; designed for minimal RAM and near-flat scaling as tabs grow.

`Rust` · `browser engine` · `rendering` · `JavaScript interpreter`

### [MoonHunt Download Manager](https://github.com/2sulraw/MoonHunt-DownloadManager)

A desktop download manager built with Tauri 2 and bundled with `aria2c`. Fast
multi-connection downloads in a small native shell.

`Vue` · `Tauri` · `TypeScript` · `Rust`
